# 4. Formulário de feedback dos testadores

O material pede um formulário para registrar **bugs, sugestões de melhoria e prints das telas com erro**. Há três formas de enviar, escolha a mais fácil para cada colega:

1. **GitHub Issues (preferencial):** em [Issues → New issue](https://github.com/Brunoredbov/sweet-bites/issues/new/choose), escolha **🐞 Reportar um bug** ou **💡 Sugerir melhoria**. É possível arrastar prints direto no formulário.
2. **Arquivo Word:** preencha [`formulario-de-feedback.docx`](formulario-de-feedback.docx) e devolva por e-mail ou WhatsApp, com os prints.
3. **Texto:** copie o modelo abaixo numa mensagem.
